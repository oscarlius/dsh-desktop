# 个人 Skill

在设置中打开「Skill 管理」，可以查看全局可用技能、预览技能文件，以及添加、启用或移除自己的技能目录。目录配置保存后生效，无需重启；移除目录不会删除其中的文件。项目和预设附带的技能仍通过对话中的 `/` 使用。

## 让 Agent 创建

1. 打开一个对话，再到「设置 → Skill 管理」。
2. 点击「让 Agent 帮我创建」，输入框会填入 `/create-personal-skill` 和用途提示。已有草稿会保留。
3. 补充技能的用途、输入及期望结果后发送。Agent 会使用现有文件工具，将技能保存到管理页显示的默认用户目录：`<DSH_HOME>/skills/<技能名称>/SKILL.md`。
4. 创建完成后，刷新技能列表查看，或在对话中使用 `/<技能名称>`。技能文件也可以通过原有文件预览和编辑流程维护。

这使用 Harness 官方的 Skill 注册表、文件发现与调用能力。技能正文以 `name`、`description` 的 YAML frontmatter 开头；新增或编辑后由官方文件提供方刷新。

个人 Skill 当前保存在本机用户目录，随用户数据保留。此入口不发布到其他员工，也不实现 P7 公司级 Skill 下发。

## 设置入口

「版本管理」已独立为设置 Tab，沿用原有 P7 更新源和差分更新流程。本机网页可使用同一 Skill 管理页；应用更新安装需在桌面客户端执行。
